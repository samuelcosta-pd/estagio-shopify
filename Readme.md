# Estágio Shopify - WebJump Fase 2 (Sprint 1)

Este repositório contém as atividades e exercícios práticos desenvolvidos por **Samuel Costa** durante a Sprint 1 do programa de estágio da WebJump (Fase 2), com foco no ecossistema Shopify e nivelamento em JavaScript.

## 🗂️ Estrutura do Repositório

O repositório está organizado na pasta `exercicios/semana-1`, contendo as seguintes atividades:

### 1. Apresentação Pessoal
* **`sobre-mim.md`**: Um breve resumo sobre mim, por que escolhi o desenvolvimento web e o que espero aprender durante este programa de estágio.

### 2. Fundamentos de JavaScript
* **`calculadora.js`**: Implementação de uma calculadora simples em JavaScript, com funções básicas como soma, subtração, multiplicação, divisão (com tratamento de divisão por zero) e cálculo de porcentagem, acompanhada de testes manuais.

### 3. Caça aos Bugs (Debugging)
* **`caca-bugs.md`**: Documento detalhando a análise de quatro trechos de código com bugs (validação de e-mail, busca em array, cálculo de desconto e formatação de preço). Explica o erro de cada trecho e propõe a solução.
* **`caca-bugs-corrigidos.js`**: O código final com todos os problemas resolvidos, utilizando boas práticas e testes para garantir o funcionamento correto e tratar *edge cases*.

### 4. Experiência: Desenvolvimento Com e Sem Inteligência Artificial
Nesta atividade, o objetivo foi resolver quatro pequenos desafios algorítmicos (inverter string, contar vogais, encontrar o maior número em um array e remover duplicatas) em duas abordagens diferentes para fins de comparação.
* **`sem-ia.js`**: Desafios resolvidos de forma manual, documentando o tempo gasto em cada resolução (Tempo total: ~20 minutos).
* **`com-ia.js`**: Desafios resolvidos com o auxílio de IA (GitHub Copilot), focando na geração rápida de código e testes de borda (Tempo total: ~2 minutos e 30 segundos).
* **`reflexao-ia.md`**: Uma reflexão detalhada sobre a experiência, avaliando as diferenças em relação ao tempo, qualidade do código gerado e o impacto no aprendizado. Conclui sobre quando vale a pena utilizar IA e quando o desenvolvimento manual é mais vantajoso para a evolução técnica.
